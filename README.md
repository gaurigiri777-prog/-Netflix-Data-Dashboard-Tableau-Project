# 🎬 Netflix Data Dashboard | Tableau Project

An interactive **Netflix Data Analysis Dashboard** built using **Tableau** to explore content trends, genre distribution, country-wise availability, release patterns, ratings, and content type insights.

This project helps visualize how Netflix's content library is distributed across different dimensions like **movies vs TV shows**, **genres**, **countries**, **ratings**, and **release years**.

## 📌 Project Overview

This Tableau dashboard provides business insights into Netflix’s content catalog by analyzing:

- Total Movies vs TV Shows
- Content distribution by country
- Top 10 genres
- Rating analysis
- Release year trends
- Date added trends
- Duration insights
- Description and metadata exploration

---

## 📊 Dashboard Features

### 🎥 Content Distribution
- Comparison of **Movies vs TV Shows**
- Percentage contribution of each type

### 🌍 Country-wise Analysis
- Total content available by country
- Geographic content spread

### 🎭 Genre Analysis
- Top 10 most popular genres
- Category distribution

### ⭐ Rating Analysis
- Ratings distribution
- Content maturity breakdown

### 📅 Release Year Trends
- Year-wise growth in Netflix content
- Trend analysis over time

### ⏱ Duration Insights
- Movie duration patterns
- TV show season trends

## 📈 Key Insights

- Movies dominate Netflix’s content library
- Certain countries contribute significantly more content
- Drama and International content appear among top genres
- Rapid content growth after 2015
- Diverse maturity ratings distribution
